Проектная работа "Веб-ларек"
«Веб-ларёк» — это веб-приложение интернет-магазина, реализующее функционал просмотра каталога товаров, добавления их в корзину и поэтапного оформления заказа.

Стек технологий: HTML, SCSS, TS, Vite

Структура проекта
src/ — исходные файлы проекта.

src/components/ — директория компонентов бизнес-логики и интерфейса.

src/components/base/ — директория базовых классов приложения.

Ключевые файлы:

src/pages/index.html — корневой HTML-шаблон страницы.

src/types/index.ts — декларация глобальных типов и интерфейсов.

src/main.ts — точка входа приложения (Presenter).

src/styles/styles.scss — корневой файл таблиц стилей.

src/utils/constants.ts — конфигурация глобальных констант.

src/utils/utils.ts — набор вспомогательных утилит.

Установка и запуск
Для установки зависимостей и запуска локального dev-сервера выполните в терминале команду:

Bash
npm install
npm run dev

Архитектура приложения
Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter):

Model (Слой данных) — отвечает за хранение, изменение данных и бизнес-логику.

View (Слой представления) — отвечает за отображение данных на странице и реакцию на действия пользователя.

Presenter (Слой связи) — выступает посредником, связывая данные и отображение. Реагирует на события при помощи брокера событий (Event Emitter).

В роли Presenter выступает основной файл src/main.ts, который инициализирует все классы и настраивает обработчики событий.

Типы данных (src/types/index.ts)
Основные интерфейсы и типы, описывающие структуру данных приложения:

IProduct (Товар): содержит идентификатор (id), описание (description), ссылку на изображение (image), название (title), категорию (category) и цену (price).

TPayment: описывает доступные способы оплаты (card или cash).

IBuyer (Данные покупателя): содержит выбранный способ оплаты (payment), электронную почту (email), телефон (phone) и адрес доставки (address).

IOrder (Структура заказа): расширяет данные покупателя, добавляя общую сумму заказа (total) и массив идентификаторов купленных товаров (items).

IOrderResult (Ответ сервера): содержит идентификатор оформленного заказа (id) и итоговую сумму (total).

Базовый код
Класс Api
Обеспечивает базовую логику отправки HTTP-запросов к серверу. Конструктор принимает базовый URL API и глобальные настройки.

get — выполняет GET-запрос по указанному эндпоинту. Возвращает Promise с ответом сервера.

post — выполняет запрос (по умолчанию POST) по указанному эндпоинту, передавая данные в JSON в теле запроса.

Класс EventEmitter
Брокер событий, реализующий паттерн «Наблюдатель». Обеспечивает связь между слоями приложения без прямой зависимости классов друг от друга.

on — устанавливает обработчик на определенное событие.

emit — инициирует событие, передавая подписчикам данные.

trigger — возвращает функцию, вызов которой инициирует событие с заданным контекстом.

Класс Component
Базовый абстрактный класс для всех компонентов слоя представления. Обеспечивает инструментарий для работы с DOM.

setImage — устанавливает изображение и альтернативный текст.

render — принимает данные, обновляет компонент и возвращает корневой DOM-элемент.

Слой данных (Model)
Класс Products
Управляет каталогом товаров.

Методы: setItems (обновляет каталог и вызывает событие), getItems, getProduct, setPreview (устанавливает товар для предпросмотра), getPreview.

Класс Cart
Управляет состоянием корзины пользователя. При изменениях генерирует соответствующие события.

Методы: getItems, addProduct, removeProduct, clearCart, getTotalPrice, getTotalCount, containsProduct.

Класс Buyer
Отвечает за хранение, управление и валидацию контактной информации пользователя и данных о доставке.

Методы: setField (записывает значение в указанное свойство), getBuyerInfo, clearBuyer, validate (проверяет заполненность данных и возвращает объект с ошибками).

Класс LarekAPI
Предоставляет методы для предметного взаимодействия с backend-частью приложения (использует базовый Api).

Методы: getProductList (запрашивает каталог), orderProducts (отправляет сформированный заказ).

Слой представления (View)
Все классы представления отвечают за отображение данных внутри DOM-элементов, не хранят в себе бизнес-логику и взаимодействуют с событиями.

Класс Page
Управляет отображением главной страницы.

Поля: _counter: HTMLElement (счетчик корзины), _catalog: HTMLElement (контейнер карточек), _wrapper: HTMLElement (обертка страницы), _basket: HTMLElement (кнопка корзины).

Методы (сеттеры): set counter (обновляет счетчик), set catalog (выводит массив карточек на страницу), set locked (блокирует прокрутку страницы).

Класс Modal
Управляет модальным окном.

Поля: _closeButton: HTMLButtonElement (кнопка закрытия), _content: HTMLElement (внутренний контейнер).

Методы: open() (открывает окно), close() (закрывает окно и очищает контент), render() (заполняет контент и открывает окно).

Базовый класс Card и его наследники
Отвечают за отображение карточки товара:

Card (Базовый класс).

Поля: _title: HTMLElement, _price: HTMLElement.

Сеттеры: set title, set price (при отсутствии цены выводит «Бесценно»).

CatalogItem (Наследник Card). Используется для вывода товаров в каталоге.

Дополнительные поля: _image: HTMLImageElement, _category: HTMLElement.

Сеттеры: set image, set category (управляет динамическим изменением цвета бейджа).

PreviewItem (Наследник CatalogItem). Отображает подробную информацию в модальном окне.

Дополнительные поля: _description: HTMLElement, _button: HTMLButtonElement.

Сеттеры: set description, set buttonText, set buttonDisabled (блокирует кнопку, если товар «бесценный»).

BasketItem (Наследник Card). Используется для списка корзины.

Дополнительные поля: _index: HTMLElement.

Сеттеры: set index (добавляет порядковый номер).

Класс Basket
Отображает корзину.

Поля: _list: HTMLElement (список товаров), _total: HTMLElement (сумма), _button: HTMLButtonElement (кнопка оформления).

Сеттеры: set items (обновляет список, при пустом массиве выводит «Корзина пуста»), set total, set buttonDisabled (управляет доступностью кнопки).

Класс Form и его наследники
Управляют базовыми формами. Базовый класс имеет поля _submit (кнопка) и _errors (контейнер ошибок), а также сеттеры set valid и set errors.

OrderForm (выбор оплаты и адреса).

Поля: _card: HTMLButtonElement, _cash: HTMLButtonElement, _address: HTMLInputElement.

Сеттеры: set payment (переключает стили кнопок), set address (обновляет значение).

ContactsForm (ввод контактов).

Поля: _email: HTMLInputElement, _phone: HTMLInputElement.

Сеттеры: set email, set phone (обновляют значения полей).

Класс Success
Отображает окно успешного оформления заказа.

Поля: _close: HTMLButtonElement, _total: HTMLElement.

Метод: render() (отрисовывает окно с итоговой суммой списанных синапсов).

Взаимодействие компонентов (События)
В приложении используются следующие события:

items:changed — изменение массива товаров в каталоге.

card:select — выбор карточки товара для открытия превью.

preview:changed — изменение товара в модальном окне превью.

preview:toggle — добавление или удаление товара из корзины в окне превью.

basket:changed — изменение состава корзины.

basket:open / order:open — открытие окна корзины / первого шага оформления заказа.

order.payment:change — изменение способа оплаты в форме.

order.<field>:change / contacts.<field>:change — ввод данных в инпуты форм.

buyer:changed — изменение данных покупателя в модели (запускает валидацию и распределение ошибок).

order:submit — успешный переход от формы адреса к форме контактов.

contacts:submit — итоговая отправка заказа на сервер.

success:close — закрытие окна успешного заказа.
